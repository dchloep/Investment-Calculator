# Investment Calculator

This project is a C++ application that calculates how investments grow over time using compound interest. The program allows users to enter investment information and view projected balances and interest earned, both with and without additional monthly deposits.

## Features

- Accepts user input for initial investment amount, monthly deposits, annual interest rate, and investment duration
- Calculates investment growth using compound interest
- Displays projected yearly balances and interest earned
- Compares investment growth with and without monthly deposits
- Organizes financial calculations into separate functions and classes
- Displays results in formatted tables

## Technologies Used

- C++
- Visual Studio
- Object-Oriented Programming (OOP)

## How to Use

1. Open the Visual Studio solution file (`Project2.slnx`).
2. Build and run the application.
3. Enter the requested investment information.
4. View the calculated investment growth over the selected number of years.
5. Compare the results with and without additional monthly deposits.
